WorkPiServ 背后是谁，您的 Pi 去了哪里

关于运营方、托管机制、费用和安全措施的可核实事实，以及 WorkPiServ 目前尚未做到的事。

运营主体的法律结构仍在确定中，一旦确定将在此公布。

您的 Pi 去向何处

WorkPiServ 使用唯一一个链上钱包来持有平台的 Pi，并通过内部账本记录每位 Pioneer 名下的资金。一笔订单的流程如下：

  1. 客户用 Pi 付款 付款通过 Pi 浏览器和 Pi SDK 完成。金额由服务器计算，并向 Pi API 核验，绝不采用浏览器传来的数值。
  2. Pi 留在托管中 自由职业者开展工作并交付。订单确认之前，这笔资金并不归其所有。
  3. 客户确认，或订单自动关闭 确认后，90% 归自由职业者，10% 归 WorkPiServ。若客户在交付后 5 天内未回应，订单将自动确认。
  4. 15 天安全期 订单确认后，自由职业者的收入将锁定 15 天，期满前不可提现，以防范迟到的纠纷。无论资金通过哪种方式释放（客户确认、自动确认或仲裁），服务器每次都会执行这一规则。
  5. 自由职业者申请提现 15 天期满后即可申请提现。汇出前有 48 小时的审核期（用于反欺诈），随后款项将自动发送到其 Pi 账户。最低提现额：0.5 π。

费用

项目金额扣收方式
WorkPiServ 佣金订单价格的 10%订单确认时从托管金额中扣除
WorkPiServ 其他费用无不适用

示例：一项 2 π 的服务，自由职业者得 1.8 π，WorkPiServ 得 0.2 π。

出现问题时

  • 服务从未交付：客户可在 7 天后申请退款。
  • 自由职业者无法履约：可取消订单，客户将获得退款。
  • 出现分歧：任何一方都可发起争议。资金将被冻结，由团队仲裁：退款给客户，或将款项释放给自由职业者。每项决定均有记录。

WorkPiServ 绝不会做的事

  • 绝不索取、接收或保存您的 24 个助记词或私钥。它们只能在官方 Pi 浏览器中输入。
  • 只保存 Pi SDK 提供的信息：Pioneer 标识符、用户名和公开地址。
  • 绝不要求您在平台之外付款。任何要求通过 Telegram、WhatsApp 或其他渠道付款的请求都是诈骗，请举报。

现有的保护措施

  • 只增不改的账本：每一笔余额变动都会连同变动前后的余额一并记录，且无法修改或删除。
  • 整数记账：余额以整数单位保存（1 π = 10,000,000 µπ），不会累积舍入误差。
  • 自动对账：系统每 6 小时核对一次，确认钱包足以覆盖全部余额和托管资金，出现差额即发出警报。
  • 欺诈检测：监控 7 类可疑行为（自买自卖、反复对倒、多个账户关联同一钱包等）。被标记的账户会接受审查。
  • 条款版本管理：每次更新条款，都需要您明确同意后才能付款或提现。
  • Testnet 与 Mainnet 严格分离：数据库、服务器和账户均相互独立。Testnet 上的 Pi 没有价值。
  • 应用安全：HTTPS、内容安全策略、请求频率限制，以及每次登录时在服务器端核验 Pi 身份。

技术细节请参阅白皮书（英文）。使用条款、隐私政策和 Cookie 政策可在应用页脚中找到。

WorkPiServ 目前尚未做到的事

  • WorkPiServ 是一个独立的应用，与 Pi Network 或 Pi Core Team 没有隶属关系，也未获其认可。
  • 截至目前，尚未取得 Pi 的 KYB 认证。
  • 尚未进行独立的安全审计。
  • 运营方目前还不是注册公司（见上文）。
  • 区块链交易无法撤销。首次下单请从小额开始。
